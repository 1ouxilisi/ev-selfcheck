新能源车故障自查

仪表亮灯、充不进电、续航掉了、报价看不懂——先在这里自己过一遍。

不用注册 · 不用登录 · 打开就能用

直接问：一句话说你遇到什么页面自己匹配，不用联网

报价算一算：这个数在不在谱上选项目 + 填金额

或者按现象自查六种最常见

上不了电 / READY 灯不亮
先做这些（零风险，5 分钟）
  • 钥匙在车内、钥匙电量正常（可贴近感应区试一次）
  • 挡位在 P 挡；充电枪是否还插着（部分车型插枪禁止走车）
  • 锁车，等 3-5 分钟再解锁上电，让系统重启
  • 车机不亮、门锁迟钝、仪表乱闪 —— 优先怀疑 12V 小电瓶
  • 车门、前备箱、后备箱是否关好（会触发高压互锁保护）
以上都正常，仍然上不了高压，可能是
  • 绝缘故障（高压漏电，涉水后常见）
  • 高压互锁（HVIL）回路未闭合
  • 预充回路、主接触器故障
  • BMS / VCU 故障
这些必须送修，不要反复尝试上电，反复上电可能扩大故障范围。
充不进电 / 充电特别慢
先排除外部原因（占大多数）
  • 充电枪插到底、电子锁是否锁止
  • 公共快充高峰会被分流，慢属于正常
  • 电池温度：过冷先预热再限流，过热也限流
  • SOC 高时快充功率本来就低（80% 以后明显变慢是保护策略）
  • 慢充不充：查插座有没有接地（部分车型无接地直接拒绝充电）
  • 换一个桩再试，排除桩的问题
  • 800V 车型在普通桩上跑不到峰值，是桩和车共同限制
可能是硬件（需送修）
  • OBC 车载充电机故障（慢充失效最常见）
  • 充电口温度传感器、CC/CP 信号异常
  • BMS 充电策略故障
  • 快充回路、高压接触器问题
判断技巧：慢充不行、快充正常 → 大概率是 OBC；快充不行、慢充正常 → 大概率是快充回路或桩的问题。
续航突然下降
先排除正常因素
  • 气温：冬季电池活性下降，续航打折，回暖恢复
  • 空调、暖风、座椅加热频繁使用
  • 胎压偏低、制动拖滞、四轮定位异常
  • 驾驶模式变化、能量回收等级调低
  • 频繁急加速、长时间高速
  • 表显口径切换（动态续航 / CLTC 固定续航差别很大）
  • 停放开了哨兵模式、电池预热保温，会持续掉电
需要关注的情况
  • 满电续航比新车时持续、明显下降（不是偶发）
  • 到店读 SOH：缓慢下降是正常老化，低于厂家质保阈值可申请检测
  • 电芯压差过大（一致性差）也会让可用容量变少，需要诊断仪读
判断技巧：只是"某天突然掉得快"，先看气温和驾驶模式；"这半年一直少跑 100 公里"，才需要考虑电池。
多个故障灯同时亮 / 车机黑屏
典型现象
  • 车机黑屏、卡顿，多个故障灯同时亮
  • 门锁反应慢、无法解锁、仪表乱闪
  • 高压上不去（低压是高压上电的前提）
处理
  • 先尝试搭 12V 电
  • 检查 12V 电瓶是否老化（寿命一般 3-5 年）
这条能省钱：多个故障灯同时亮，优先怀疑 12V 低压，而不是每个部件都坏了。一个电瓶几百块，被误判成"多个模块故障"可能是几千块。
动力受限 / 加速无力 / 中途限速
先在路边判断
  • 是否 SOC 极低，触发了低电量保护
  • 是否电池或电机温度异常，触发限流（跛行模式）
  • 是否刚涉水、报绝缘故障
  • 靠边停车、重新上电，看是否恢复
如果持续存在
  • 可能是加速踏板传感器、电机三相连接、MCU、高压系统故障
  • 需要读 VCU / MCU / BMS 故障码，送修
注意：跛行模式是保护机制，不是故障本身。车能慢慢开回家，说明系统在保护你，不是马上要报废。
异响 / 抖动 / 顿挫
先分辨声音来源
  • 减速器啸叫（加速时"呜呜"声，随车速变化）→ 减速器齿轮或油液
  • 电机高频啸叫（电流声）→ 多为正常电磁噪声，或电机位置传感器异常
  • 底盘"咯噔" → 悬置、衬套、球头
  • 刹车"吱吱" → 刹车片磨到极限，或新片未磨合
  • 行驶中"嗡嗡"随车速增大 → 轮胎偏磨、轮毂轴承
判断技巧：把车升起来空转，声音随车速变、不随挡位变 → 多在轮胎/轴承/减速器；声音随电机转速变 → 多在电机/电控。

第三步：这个报价贵不贵五类常见项目

看五类典型区间（示例价，不是标准价）
五个"报价异常"信号
  • 不给拆分明细，只报总数
  • 不给看旧件
  • 说"必须马上换，不然会出事"—— 用恐惧催单
  • 拒绝你拍照、拒绝你带走旧件
  • 报价明显低于市场（尤其"全新原厂电池包"）—— 低价往往对应翻新、拆机、修复件

第四步：到店照着说这六句

1."麻烦把配件费和工时费分开列一下，工时按几个小时算？"

2."这个件是原厂、品牌还是副厂？质保多久？维修单上能写吗？"

3."换下来的旧件我要看一下，可以吗？"

4."故障码能当面读一下吗？是当前故障还是历史故障？"

5."清码之后如果还复现，是不是说明确实要换？"

6."这个项目在别的店大概什么价，你们这个差在哪？"

这六句话说完，对方基本会重新给你一份更认真的报价。
